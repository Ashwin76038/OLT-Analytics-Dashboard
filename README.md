# 📊 OLT Analytics Dashboard

⭐ Real-world inspired Power BI project based on telecom/network operations data.

---

## 🧩 Project Background

This project is inspired by real business operations from my father’s telecom/network service work.

In this domain, managing customer connections, monitoring OLT (Optical Line Terminal) performance, and identifying service risks are critical for maintaining efficiency and revenue.

To explore and analyze this type of data, I designed and developed a complete Power BI dashboard that transforms raw operational data into actionable insights.

---

## 🎯 Objective

The goal of this project is to:

- Monitor customer activity (Active / Partial Active / Inactive)
- Analyze plan distribution and revenue contribution
- Evaluate OLT performance and load distribution
- Identify high-risk customers and service issues
- Support better operational and business decisions

---

## 📊 Dashboard Pages

### 🔹 1. Overview
- Total customers and status distribution
- Active vs Inactive percentage
- Customer segmentation insights

### 🔹 2. Plan Analysis
- Revenue by plan category
- High-value vs low-value customers
- Plan performance comparison

### 🔹 3. OLT Analysis
- Total connections per OLT
- Load distribution across OLTs
- Highest and lowest performing OLTs

### 🔹 4. Risk Analysis
- Inactive & partially active customers
- Risk percentage
- Potential revenue at risk
- High-risk OLTs and segments

---

## 🛠️ Tools & Technologies

- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 📁 Sample Dataset

A sample dataset is included in this repository to demonstrate the structure and logic used in the project.

### ⚠️ Important Note

The original dataset is based on real business data and is **not shared due to confidentiality and privacy reasons**.

The provided dataset is a **simulated version** created to:

- Match the structure of the real data
- Enable demonstration of the dashboard
- Allow others to explore and reuse the project

---

## 🧠 Reason for Using Sample Data

Using a sample dataset ensures:

- 🔒 Data privacy and business confidentiality are maintained  
- 📊 The dashboard remains fully functional for demonstration  
- 👨‍💻 Others can understand the data structure and replicate the project  
- 💼 The project can be safely shared publicly on GitHub  

This approach reflects real-world practices where sensitive business data cannot be publicly exposed.
